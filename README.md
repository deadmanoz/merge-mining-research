# merge-mining-research

Research tooling and datasets for studying Bitcoin merge mining and what it can
reveal about mining pools, block propagation, stale blocks, and the
canonical-versus-stale record.

This repository is being prepared for public release. The code, datasets,
methodology notes, and generated research outputs are still being reviewed and
curated before they are synced here.

Until the full release is published, this README is only a placeholder for the
public repository location.
